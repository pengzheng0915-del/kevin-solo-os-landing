关于赚钱与说服，哪些观点需要谨慎判断

海外方法导读 学习方法的终点不是记住更多，而是能在真实问题中使用

原始内容Making Money Is Spiritual If You Learn These Unethical Skills，Dan Koe

适合谁持续阅读和学习，却难以把知识变成判断、作品或工作结果的人

Kevin 判断用一个具体任务检验理解、迁移与独立完成，而不是追求速成

不要照搬不把第一次完成当熟练，不用阅读量或记忆量代替实际能力

这是一篇海外方法导读。原始内容来自 Dan Koe 的英文文章《Making Money Is Spiritual If You Learn These Unethical Skills》。下面保留原文提出的问题，并补上国内职场语境中的适用条件、证据边界和可执行验证。

文章批评一种对商业、营销和销售的道德化排斥。更稳妥的判断是：不必接受操纵式销售，但需要理解价值如何被说明、交换和交付。

这是一种幻觉。

这种所谓的“高尚视角”，在这篇文章的语境里是误解、缺乏共情和怨恨的混合体。它的意识层次，并不比那些被他们鄙视的“油滑销售”更高。

就像民主党和共和党互相攻击，无神论者和有神论者彼此否定。一旦陷入这种狭隘的争论，你就长期看不到全局真相。

全局真相是什么？

如果你不创办一家提供信息、教育和产品、旨在让人类变得更好的企业，那么不道德的企业就会在没有竞争的情况下崛起，让世界变得更糟。

不道德的商业充斥市场，恰恰是因为你没有自己想象的那么清醒、那么聪明。

是否创业是个人经营选择，不创业不等于助长不道德行为。

你一边妖魔化金钱和商业，一边却在一家按你的标准来看很可能不道德的公司里打工。这家公司可能让大众生病，可能参与轰炸别国，可能把员工锁死在机械化的流程里，让他们长期不敢发挥潜力。

而那些在健康、财富、关系和幸福领域提供教育、课程和教练服务的人，正在从根源上推动正向行为改变。他们被骂成“信息差收费”、“骗局”，但他们解决的是人类最真实的问题。

教育，是让个体有能力解决自身问题，而并非依赖暂时的缓解。如果旧的教育体系只是在为自身利益训练劳动力，那么新的数字社会，由价值创造者组成，就是一条现实的出路。

是否行动要看问题、责任与现实约束，不能用道德羞耻推动创业或购买。

如果你有10年以上的行业经验，却还在用“我不屑于搞营销”来安慰自己，那你的经验正在贬值。

你的知识、你的判断、你踩过的坑，都是别人的解药。问题是，你愿不愿意把它卖出去。

这篇文章的原作者是 Dan Koe。Kevin 在这里保留“表达价值需要说服”的命题，同时提醒你区分诚实呈现、夸大承诺和操纵行为；是否商业化，仍要回到你的证据、边界与真实需求。

Kevin 的判断：学习必须进入真实任务

关于“关于赚钱与说服，哪些观点需要谨慎判断”，可以保留的是缩短输入到实践的距离。判断是否学会，要看你能否独立处理变化、解释取舍，并留下别人能够检查的结果。

阅读《关于赚钱与说服，哪些观点需要谨慎判断》时，请把原作者经历、Kevin 的筛选意见和你自己的事实分别记录。你的岗位、行业、家庭责任、现金流与可投入时间不同，原文中的顺序和强度也需要调整。
