什么证据会改变当前判断

判断可以被新证据更新，这不是算命

  • 如果出现第一笔真实付费（哪怕金额很小）
    → 把"先做需求验证"升级为"先做一次边界清楚的小交付"，并开始写交付说明。
  • 如果连续 3 次以上有人主动带着同一个具体问题来找你
    → 需求信号成立，优先路径的确定性提高，可以考虑开始设计第一版交付。
  • 如果你每周可稳定投入时间仍然很低
    → 只保留轻验证动作，不要启动重服务、长内容系列或复杂产品。
  • 如果连续两次验证都没有拿到任何具体问题或继续动作
    → 当前假设应暂停，回到经验萃取，换一个人群或换一个问题重新验证。

另外，这些是明确的暂停线：如果没人愿意继续聊具体问题，不要为这个方向继续花钱加码。 如果 7 天内没有真实对话、追问、反馈或试单，停止产品化，回到经验萃取。 如果交付物、不包含范围和判断标准没有写清，先不要正式提高价格。
